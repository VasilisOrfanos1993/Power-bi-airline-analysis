# Power BI Airline Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard developed to analyze airline performance, customer satisfaction and operational metrics.

The dashboard was developed as part of a Data Analytics project at Rome Business School, focusing on transforming passenger and flight data into meaningful business insights.

## Objectives

- Analyze passenger distribution and travel patterns
- Evaluate customer satisfaction
- Compare performance across travel classes
- Analyze operational metrics such as delays and in-flight services
- Identify patterns in customer experience

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Visualization

## Dashboard Pages

The dashboard includes three interactive pages:

- Executive Overview
- Customer Experience
- Operational Performance

## Key Features

- KPI cards
- Interactive visualizations
- Customer satisfaction analysis
- Passenger segmentation
- Flight and operational analysis
- Interactive filters and slicers
- DAX-based calculations

## Academic Context

Developed as part of a Data Analytics project at **Rome Business School**.
